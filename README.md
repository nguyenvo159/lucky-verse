# LuckyVerse — The Ultimate Lucky Draw Experience

Website quay thưởng tương tác đa phong cách (**Premium Playful Arcade + Modern Motion Design**) hỗ trợ tối đa **1.000 người tham gia** và hoạt động 100% phía client.

## Các chế độ trò chơi (6 Game Modes)

1. **Lucky Wheel (Vòng Quay May Mắn)**: Vòng quay HTML5 Canvas sắc nét với đèn LED viền, kim chỉ vật lý và âm thanh tích tắc theo từng ô.
2. **Lucky Lottery (Quay Số Truyền Hình)**: Bảng điện tử LED chuẩn gameshow truyền hình với đếm ngược 3-2-1 và khóa từng chữ số hồi hộp.
3. **Mystery Box (Hộp Quà Bí Ẩn)**: Không gian kho báu lơ lửng cho phép chọn trực tiếp từng hộp quà hoặc bóc thăm ngẫu nhiên.
4. **Duck Race (Đua Vịt Về Đích)**: Đường đua hồ nước hoạt họa với khán đài cổ vũ, phao chướng ngại vật và các chú vịt hóa trang đua nước rút về đích.
5. **Super Jackpot (Máy Quay Jackpot)**: Cỗ máy Arcade 3 trục quay neon với cần gạt tương tác và 3 chủ đề màu sắc.
6. **UFO Abduction (UFO Bắt Người Trong Thành Phố)**: Thành phố đêm 2.5D parallax sống động với hàng trăm cư dân đa dạng và phi thuyền UFO chiếu tia Tractor Beam bắt đúng người chiến thắng.

## Hướng dẫn khởi chạy và Build

### 1. Cài đặt thư viện
```bash
npm install
```

### 2. Chạy môi trường phát triển (Development)
```bash
npm run dev
```

### 3. Chạy kiểm thử tự động (Unit & QA Tests)
```bash
npm test
```

### 4. Đóng gói sản phẩm (Production Build)
```bash
npm run build
npm run preview
```
